Honestly, on my own initiative, I wanted to try setting up my own homelab — as you can see at https://taksiegra.ovh/changelog, I eventually managed to pull it off. The name taksiegra was basically coined by Pioye_, as far as I can remember after submitting an insane score and a short discussion about what to name the site.
However, after the site was created, there wasn't much going on here — until I started experimenting with Cloudflare Tunnel. Using that, and of course AI, I managed to set up an osu! server called taksiegra, using nginx as a reverse proxy and CNAME records in DNS. It took me around 5 days, but in the end everything works great. I handle the development myself, occasionally testing things with AI.
