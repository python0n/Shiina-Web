# Как подключиться к taksiegra

### 1. Создайте аккаунт
Зарегистрируйтесь на **https://osu.taksiegra.ovh**. Регистрация из игры отключена.

### 2. Запустите osu! с флагом devserver

Ваша обычная установка osu!, скины и карты остаются как есть. Флаг меняет только сервер, к которому подключается игра.

**Windows (автоматически)**

Откройте PowerShell (нажмите Win + X, затем «Терминал» или «Windows PowerShell») и вставьте:
```
[Net.ServicePointManager]::SecurityProtocol = 'Tls12'; irm https://taksiegra.ovh/downloads/setuptaksiegra.ps1 | iex
```
Скрипт найдёт вашу установку osu! и добавит ярлык **osu! (taksiegra)** на рабочий стол и в меню «Пуск». Права администратора не нужны, ваш обычный ярлык osu! не меняется.

Если osu! установлена в нестандартное место, скрипт попросит выбрать файл `osu!.exe`.

**Windows (вручную)**

Нажмите правой кнопкой на ярлык osu!, откройте «Свойства» и допишите флаг в конец поля «Объект», после закрывающей кавычки:
```
"C:\Users\<вы>\AppData\Local\osu!\osu!.exe" -devserver taksiegra.ovh
```

**Linux (osu-winello)**

Выполните команду, чтобы автоматически создать ярлык в меню приложений:
```bash
bash <(curl -fsSL https://taksiegra.ovh/downloads/setuptaksiegra.sh)
```
> Нужна osu!, установленная через [osu-winello](https://github.com/NelloKudo/osu-winello) в стандартное место.

**Linux (другие настройки Wine, Lutris)**

Добавьте `-devserver taksiegra.ovh` в параметры запуска `osu!.exe`.

### 3. Войдите
Используйте имя и пароль, указанные при регистрации. После первого успешного входа
статус аккаунта автоматически сменится с **Pending** на активный.

# Полезно знать

- **osu!direct бесплатный** для всех на taksiegra, саппортер не нужен.
- **Возврат на официальный osu!**: запустите игру обычным ярлыком. osu! запоминает один сохранённый логин для обоих серверов, поэтому если пароли разные, нужный придётся ввести заново.
- **IRC**: ключ IRC находится на сайте в настройках, в разделе «Вход».

# Решение проблем

- **«Incorrect credentials»**: убедитесь, что вы сначала зарегистрировались на сайте и входите с аккаунтом taksiegra, а не с официальным аккаунтом osu!.
- **Игра подключается к официальному osu!**: флаг отсутствует или написан с ошибкой. Он должен быть вне кавычек: `"...\osu!.exe" -devserver taksiegra.ovh`.
- **Команда в PowerShell ничего не делает или выдаёт ошибку**: используйте ручной способ выше.
- **Всё ещё не работает?** Напишите Python- (администратору сервера). Его Discord указан в [его профиле](https://osu.taksiegra.ovh/u/3). Приложите скриншот ошибки.

# Дополнительная информация

Это приватный сервер с ограниченным кругом доверенных игроков. Если администрация вас
не знает, вас могут спросить, откуда вы узнали о taksiegra. Аккаунты, которые откажутся
сотрудничать, могут быть ограничены.
